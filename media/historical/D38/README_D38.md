## 问题定位（证据见 `D38_evidence.md` 与渲染对照）

1. **3 个错误生成的红色长方体**：`T23052218322040428::cabinet.1/2/3`（body/panel/sign，FIRE cabinet red），来自 fire-system 批次的 ray-position proxy。三处落点 (-19.5,-42.8)、(-25.6,-30.2)、(-7.6,-76.4) 在注册粗模同一位置均无任何设备（俯视渲染与粗模切片对照确认）。cabinet.4 (-12.0,-79.0) 落点粗模有结构支撑，保留。
2. **缺失的组合电器节**：西侧 VC-B GIS 行三处粗模有完整间隔设备而模型只有母线走廊的位置：G1 (-22.4,-57.8)（母联4800 与 #1主变4801 之间）、G2 (-27.6,-47.3)（分段4100 与 #1主变4801 之间）、G3 (-40.9,-17.2)（4D76 与 2899 之间）。粗模设备高 2.2–3.3m、无 4m 以上套管。
3. **红色消防室与消防砂箱**：粗模 Tile_51 中 (-23.3,-38.9) 有红色小房（核心 ≈2.25×2.85×2.26m，近似立方体）及其南北各一个 ≈0.9m 立方砂箱，均未建模。

- 补建：红色消防室立方体（含薄底座）+ 2 个消防砂箱，落地用 B34 地面网格 raycast；消防室红色，砂箱黄色（颜色为惯例推定，无影像证据）。
