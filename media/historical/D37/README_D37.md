# D37 小设施正式续作

D37 从 B36 R3 的只读基线另存，承接 B36 明确留下的三类小设施：GIS 矮杆投光灯、局部井盖与沟盖板、白色标识桩。D37 的脚本、计划、验证和输出都放在 D37 专属路径中；不回写 B36 目录，不改动任何历史文件。

D37 取代 C37 测试版。C37 的几何与坐标计划可用，但其渲染产物全部为空图（五张 PNG 内容一致、无任何几何），且未做重读验证；C37 目录与其输出仅作测试保留，不作为正式成果。D37 沿用 C37 测试计划的候选坐标与证据，仅做两处修正：

1. 井盖组件整体下移 0.025 m，使混凝土井圈底面落地（C37 测试版井圈悬空 0.025 m）。
2. 渲染管线加固：逐场景显式指定渲染场景并立即校验像素方差，空图自动重渲染一次仍空则报错中止；新增建筑侧沟盖/井盖与标识桩两个审查场景（764/765）。
3. 落地方式改为对 B34 真实地面网格做世界空间 raycast：npz 平滑网格与地面网格在局部相差可达 0.08 m，直接插值会导致小设施可见悬空。

## 基线

- 输入工程：`../output/installation_B36/site_B36_transformer_bus_racks_r3.blend`
- 输入 SHA-256：`b6bbc3caeffdf72ca52df2dd5e01234269fe652827131e64f1f8a1da7ef502e8`
- B36 规模：36,812 个对象、743 个场景、842 个集合、400 个材质；整站场景包含 7,116 个站内对象。
- B36 已验证：保存后重读一致、既有对象/场景/站内变换保持、组件库往返一致、新几何有限、主母线与既有设备无非预期表面穿插。
- B36 两台主变低位母线架和墙侧接口已经冻结，D37 不重建这些部件。

## D37 范围

本轮按照片优先和粗模对照建立一个小而可审计的候选批次：

- 4 个 GIS 矮杆投光灯，布置在两侧 GIS 行外侧通道；
- 8 个圆形井盖候选，布置在主环路和入口通道的开敞区域；
- 6 个局部沟盖板单元，沿主建筑东侧外缘形成一段可见沟盖带；
- 6 个白色标识桩候选，布置在两侧 GIS 行端部和通道边缘。

坐标、尺寸、朝向和证据等级记录在 `plan_D37.json`。小设施位置是由 B35 俯视粗模参考、B34 已正则化道路/地面和 B36 留项约束得到的建模候选，不是独立测绘成果。没有为它们添加不可见地下管线、用途铭牌或无法从照片确认的编号。

## 建模约束

1. 所有新几何使用 `D37_` 前缀和独立集合；重复部件通过集合实例共享。
2. 每个地面单元通过对 B34 真实地面网格做世界空间 raycast 落地（npz 平滑网格插值仅作兜底），保留地面“粗模平滑、非测量”的限制。
3. 参考场景可以显示既有注册粗模，整站清洁场景只显示 B36 整站和 D37 小设施。
4. D37 主文件另存为新文件，组件库另存为新文件；不对输入 B36 文件执行保存。
5. 若后续照片或实测与本计划冲突，应在 D37 内修订计划并递增版本，不覆盖 B36。

## 运行与验收

在 Blender 5.1.2 环境中执行 `build_D37.py` 生成工程、组件库和预览；执行 `validate_D37.py` 重读工程并检查输入哈希、既有对象与整站变换保持、有限几何、集合实例共享、地面接触、相机取景与渲染产物非空。最终记录在 `output/installation_D37/D37_completion.md`、`D37_manifest.json` 和 `D37_validation.json`。
